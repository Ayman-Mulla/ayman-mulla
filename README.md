## 🎧 Featured project: VibeTune
A mood-based music app concept designed in Figma. The main design challenge was responding to a listener's mood without feeling jarring, so I designed an **Emotion-Stable Recommendation Algorithm** along with **Mood History** and **Preferences** flows that keep users in control.

I took it from competitor analysis and task analysis through to a persona, user flows, and high-fidelity screens.
